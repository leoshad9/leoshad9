### 🚀 Featured Projects

#### 🏥 [MedOps: Hospital Operations Platform](https://github.com/leoshad9/medops) &nbsp;·&nbsp; [🌐 Live Demo](https://medops.duckdns.org/)

Full-stack healthcare operations platform for secure clinical workflows, appointment management, and AI-assisted report summarization.

- 🔐 **Security:** JWT authentication with role-based access control (RBAC)
- 📨 **Event-driven:** Kafka-backed workflows for decoupled processing
- ⚡ **Performance:** Redis caching on hot read paths
- 🛡️ **Resilience:** Resilience4j circuit breakers and fault tolerance
- 🤖 **AI service:** FastAPI microservice that summarizes clinical PDFs
- 🚢 **Delivery:** Dockerised and deployed on AWS EC2 through GitHub Actions
